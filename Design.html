Product

✨ Proses Perancangan Sistem & Rekayasa Aplikasi EduFinance ✨
1

Riset Aplikasi (Identifikasi Masalah)

Menentukan masalah atau kebutuhan yang ingin diselesaikan melalui program EDUFINANCE. Banyak orang, terutama siswa, belum terbiasa mencatat pemasukan dan pengeluaran sehingga kondisi keuangan sering tidak terkontrol.

2

Pengumpulan Ide

Memilih ide pengembangan program EDUFINANCE, yaitu program sederhana untuk membantu pengguna mencatat pemasukan dan pengeluaran, melihat ringkasan keuangan, serta mengekspor laporan ke Excel agar pengelolaan keuangan lebih teratur.

3

Design Logo (Filosofi Brand)

Bentuk hewan rubah melambangkan sifat cerdas dan strategis dalam mengatur keuangan. Ekor besar melambangkan tabungan masa depan, sedangkan warna pastel mint, kuning, biru, serta warna hitam menjadi identitas brand kami.

4

Pembuatan Website

Website dibuat menggunakan HTML, CSS, dan JavaScript. Desain responsif agar bisa diakses dari berbagai perangkat. Fitur slideshow memudahkan pengguna untuk melihat tutorial step-by-step.

5

Testing & Publikasi

Website diuji untuk memastikan semua fitur berjalan dengan baik, kemudian dipublikasikan melalui GitHub Pages agar mudah diakses oleh semua orang.
